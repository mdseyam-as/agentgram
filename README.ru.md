# Agentgram — Telegram Desktop с ИИ-агентом и Bot Studio

[English](README.md) · **Русский**

Agentgram — **неофициальный** форк [Telegram Desktop](https://github.com/telegramdesktop/tdesktop)
(нативный клиент на C++/Qt, лицензия GPLv3 с исключением OpenSSL). Вы входите
в свой настоящий аккаунт Telegram и получаете все возможности Telegram Desktop,
а сверх того:

* **ИИ-агента**, который читает, ищет, пересказывает и действует в ваших чатах;
* **Bot Studio** — конструктор Telegram-ботов: собирайте ботов мышкой или на
  JavaScript и запускайте их прямо в приложении, без серверов и деплоя.

Agentgram не связан с Telegram FZ-LLC.

## ИИ-агент

* **Боковая панель** — кнопка ✦ в шапке любого чата или *Меню → ИИ-агент*.
  Открывается справа от главного окна или в отдельном окне.
* **Инструменты**: список и поиск чатов, чтение истории, поиск по всем чатам
  и внутри чата, сводка непрочитанного, участники групп, папки, отправка,
  пересылка, правка, удаление и закрепление сообщений, отметка прочитанным,
  создание групп, добавление участников, черновики в поле ввода, открытие
  чатов — и создание ботов в Bot Studio.
* **Безопасность**: всё, что что-то меняет, показывается карточкой
  «Разрешить / Отклонить», пока вы не выберете «разрешать всё».
* **Провайдеры**
  * вход через ChatGPT (OAuth, по вашей подписке ChatGPT Plus/Pro)
  * OpenRouter (OAuth PKCE или ключ API)
  * OpenAI, Anthropic Claude, Google Gemini, DeepSeek, xAI, Mistral, Groq (ключи API)
  * Ollama / LM Studio / любой OpenAI-совместимый сервер
* Потоковые ответы с Markdown; списки моделей подтягиваются у провайдера
  автоматически, быстрая смена модели — щелчком по заголовку панели.
* Переключение тёмной и светлой темы прямо в панели.

## Bot Studio *(пока в Linux-версии)*

*Меню → Bot Studio* открывает отдельное окно, где вы создаёте и запускаете
своих Telegram-ботов. Бот работает **внутри Agentgram**, пока приложение
открыто: он получает сообщения через Telegram Bot API, поэтому ничего не нужно
размещать на сервере или деплоить. Включённые боты запускаются вместе с
приложением.

* **Редактор узлов в стиле n8n / Make**: бесконечный холст с масштабом
  (Ctrl + колесо) и перетаскиванием, связь протягивается мышкой от точки
  справа у блока к другому блоку, «+» у свободного выхода или отпускание на
  пустом месте открывает выбор узла с поиском, связь удаляется щелчком, панель
  настроек выезжает справа, запуск (команды, ключевые слова, «всё остальное»)
  — тоже узлы, кнопка «Упорядочить» раскладывает схему, Ctrl+Z / Ctrl+Y,
  Delete, Ctrl+D.
* **Визуальный конструктор** для тех, кто не программирует. Бот — это схема
  из карточек-сообщений на холсте:
  * сообщение с текстом (`{first_name}` и другие подстановки), картинкой и
    кнопками;
  * каждая кнопка ведёт к другому сообщению или открывает ссылку — стрелки на
    схеме показывают куда;
  * сообщение может ждать ответ пользователя (текст, телефон с кнопкой
    «Отправить номер», число, e-mail) и сохранять его;
  * «присылать мне ответы» превращает ветку в форму заявки — собранные ответы
    приходят вам в Telegram;
  * команды (`/start`, `/help`…), ключевые слова и что делать с любым другим
    сообщением: показать блок, ответить текстом или **ответить через ИИ**.
* **Типы блоков**: *сообщение* (текст, фото, видео, файл, аудио, кнопки,
  вопрос с проверкой ответа), *условие* (ветвление по ответам: равно, содержит,
  больше, меньше, заполнено), *ответ ИИ* (текст пишет нейросеть по вашему
  заданию с подстановками), *действия* (записать значение, начислить баллы,
  написать вам, отправить в чат или канал, передать данные на вебхук — Make,
  Zapier, Google Таблицы, сохранить заявку). Перед любым блоком можно
  подождать N секунд с «печатает…».
* **Ещё блоки**: *случайный выбор* (колесо удачи, A/B-тесты), *чат с
  оператором* (клиент пишет боту, вы отвечаете из Telegram ответом на его
  сообщение), условия по **подписке на канал**, **меткам** пользователя и
  **рабочему времени**; действия «посчитать по формуле», «добавить метку»,
  **«напомнить позже»** (уроки по дням, брошенная корзина), запрос к любому
  API с сохранением поля из ответа. Ответ может быть геопозицией или фото,
  нажатую кнопку можно сохранить как ответ.
* **Магазин**: список товаров с категориями, ценами, фото и настройками
  доставки (*🛍 Товары*), блоки *каталог* (карточки с листанием и кнопкой
  «В корзину»), *корзина* (± количество, доставка, минимальная сумма) и
  *заказ и оплата* — при получении, **звёздами Telegram** или картой через
  любого платёжного провайдера @BotFather. Заказы приходят вам в Telegram с
  кнопками статусов (принят, в пути, выполнен, отменён), покупатель получает
  сообщение о каждом; команда `/admin` в боте показывает статистику.
* **Аудитория**: пользователи, активные за 7 дней, заблокировавшие; таблицы
  заявок и **заказов** с выручкой, сменой статуса и выгрузкой в CSV
  (открывается в Excel); **рассылка** всем или только пользователям с меткой.
* **Шаблоны**: интернет-магазин, доставка еды, платный доступ за звёзды, меню
  и ответы, сбор заявок, запись на услугу, поддержка с оператором, бонус за
  подписку, квиз с баллами, колесо удачи, мини-курс по дням, ИИ-ассистент, с
  чистого листа.
* **Создание с ИИ**: опишите бота своими словами — агент зарегистрирует его в
  @BotFather (с вашим подтверждением), соберёт схему, запустит и проверит лог.
  Любые изменения тоже можно описать в поле «✦ Сделать».
* **Режим кода** для разработчиков: один JavaScript-файл на встроенном движке
  QuickJS с небольшим фреймворком — `bot.command / hears / action / on`,
  inline- и обычные клавиатуры, сессии чатов `ctx.session`, постоянное
  хранилище `db`, `ai.ask` / `ai.chat` через ИИ-провайдера Agentgram,
  `http` / `fetch`, таймеры. Подсветка синтаксиса, проверка кода при
  сохранении, бесконечный цикл прерывается через 5 секунд.
* **Логи** в реальном времени (входящие сообщения, `console.log`, ошибки с
  номером строки) и вкладка **Данные** со всем, что сохранил бот.

## Дизайн интерфейса: Vanilla и AgentUI

В **Настройки → Настройки чатов → Дизайн интерфейса** две карточки:

* **Vanilla** — классический Telegram, как в официальном клиенте.
* **AgentUI** — дизайн Agentgram: панели из матового стекла поверх обоев
  (колонка чатов, папки, шапка чата, поле ввода, панель агента),
  матовые контекстные меню и размытый фон под окнами, скользящая подсветка
  строк в списке чатов, анимированный градиент обоев, переход между
  дизайнами раскрывается кругом из точки клика.

У AgentUI есть тёмный и светлый варианты, они переключаются ночным режимом.
При возврате на Vanilla восстанавливается тема, которая была до AgentUI.
Палитры генерирует `Telegram/build/agentgram/agentui_themes.py`.

## Прочее

* Свой `api_id` можно указать прямо в приложении (на стартовом экране или в
  настройках агента) или через `AGENTGRAM_API_ID` / `AGENTGRAM_API_HASH`.
* Отдельная папка данных; автообновление отключено (оно поставило бы
  официальный Telegram).
* Ключи ИИ, токены и боты хранятся в зашифрованном локальном хранилище
  аккаунта.

## Сборки

GitHub Actions в этом репозитории собирают:

* **Linux x64** (переносимая, glibc 2.28+) — `.github/workflows/agentgram-linux.yml`,
  при каждом пуше.
* **Windows x64** — `.github/workflows/agentgram.yml`, запускается вручную.
  Bot Studio в Windows-сборку пока не входит.

Ветка одна — `agentgram`, для обеих платформ: различия платформ решаются при
сборке (`if (LINUX)` в CMake).

Задайте секреты репозитория `TDESKTOP_API_ID` / `TDESKTOP_API_HASH`, чтобы
вшить в сборки свои ключи; иначе используются ограниченные тестовые.

Локальная сборка — по инструкциям Telegram Desktop в [docs](docs/); для
быстрой локальной Linux-сборки добавьте `-D AGENTGRAM_FAST_BUILD=ON`
(облегчённая оптимизация кода приложения, нужно гораздо меньше памяти).
Скрипт сборки под Windows в один клик — `Telegram/build/agentgram/build_windows.bat`.

Код: ИИ-агент — `Telegram/SourceFiles/ai_agent/`, Bot Studio —
`Telegram/SourceFiles/bot_studio/` и `Telegram/Resources/bot_studio/`.
