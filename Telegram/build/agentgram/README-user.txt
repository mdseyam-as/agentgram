Agentgram — Telegram с встроенным ИИ-агентом
=============================================

Неофициальный клиент на основе Telegram Desktop (GPLv3). Вход — через ваш
настоящий аккаунт Telegram (QR-код или номер телефона).

Как пользоваться ИИ-агентом
---------------------------
1. Откройте любой чат и нажмите значок ✦ в верхней панели чата
   (или Меню → «ИИ-агент»). Справа откроется панель агента.
2. Нажмите на заголовок панели или шестерёнку и выберите провайдера:
   - ChatGPT (OAuth) — вход через подписку ChatGPT Plus/Pro, без ключа;
   - OpenRouter — вход через OAuth или ключ API;
   - OpenAI, Anthropic, Google Gemini, DeepSeek, xAI, Mistral, Groq — ключ API;
   - Ollama / свой сервер — локальные модели по адресу API.
3. Пишите задачи: «сделай сводку непрочитанного», «найди, где обсуждали
   отпуск», «подготовь ответ в этот чат», «перешли последнее сообщение Ане».
   Отправку, пересылку, удаление и другие изменения агент сначала
   показывает на подтверждение.

Кнопка ↗ в панели открывает агента в отдельном окне, кнопка луны/солнца
переключает тёмную и светлую тему.

api_id Telegram
---------------
Сборка по умолчанию использует тестовый api_id, у которого жёсткие лимиты.
Для постоянной работы получите свой на https://my.telegram.org → API
development tools и укажите его на стартовом экране («Указать свой api_id
Telegram») или в настройках ИИ-агента. Можно также задать переменные окружения
AGENTGRAM_API_ID и AGENTGRAM_API_HASH.

Данные хранятся отдельно от официального Telegram Desktop
(Windows: %APPDATA%\Agentgram, Linux: ~/.local/share/AgentgramDesktop).
